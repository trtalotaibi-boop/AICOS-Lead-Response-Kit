# AICOS FREE — Quick Start

This is a functional preview of AICOS Lead Response Kit — Clinics Edition.

## Included
- Sample clinic lead
- Lead ID and phone validation
- Configurable service/source scoring
- HIGH / MEDIUM / LOW priority
- Owner-review output

## Not included in FREE
Data Table persistence, duplicate detection/upsert, full follow-up preparation, SLA/channel logic, and the full commercial documentation.

## Run it
1. Download `free/AICOS_Lead_Response_Kit_Clinics_FREE.json`.
2. Import it into your own n8n instance.
3. Optionally edit `Lead Input (Sample)`.
4. Run `Manual Trigger`.
5. Inspect `Owner Review Output`.

No credentials, API keys, external AI API, WhatsApp, SMS, or email connection is required for this demo.

Use demo or authorized data only.
