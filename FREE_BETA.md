# Free Beta — AICOS Clinics Edition v1.0

This version is free to try for evaluation and feedback. No product payment, card, checkout or paid API is required. If you choose paid n8n hosting, that separate expense is your choice.

The purpose is to learn from real installation attempts and voluntary feedback. Try the manual workflow with synthetic leads, inspect the output, repeat a lead to check the update path and tell us what worked or was unclear. See [BETA_FEEDBACK.md](BETA_FEEDBACK.md).

The owner accepted the isolated local verification on 2026-10-03: 15/15 cases, clean install, accepted LOW/MEDIUM/HIGH and no outbound send. Multiple leads were separate executions. Validate your own installation before deciding whether it is suitable for sensitive real records.

The plan may change later, but no future price, permanent free access, support response time or feature date is promised. [LICENSE_OR_USAGE_TERMS.md](LICENSE_OR_USAGE_TERMS.md) defines current beta evaluation use. No usage telemetry or feedback transmission is built into the workflow.
